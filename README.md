# Savanna Realty Group

Nairobi real estate website for property buyers, sellers, investors and
diaspora Kenyans. Built with Next.js 14 (App Router) and TypeScript,
structured after the Uptown template's page hierarchy (home, properties,
property single, agents, blog, blog single, about, services, contact).

## Getting started

```bash
npm install
npm run dev        # http://localhost:3000
```

```bash
npm run typecheck  # tsc --noEmit
npm run build      # production build
npm start          # serve the production build
```

## Environment variables (all optional, used when deployed to Vercel)

| Variable | Purpose |
|---|---|
| `KV_REST_API_URL`, `KV_REST_API_TOKEN` | Vercel KV (Upstash REST). Without them, API routes fall back to the bundled JSON data and in-memory writes. |
| `WHATSAPP_TOKEN`, `WHATSAPP_PHONE_NUMBER_ID`, `WHATSAPP_RECIPIENT` | WhatsApp Cloud API credentials for lead notifications from `/api/valuation` and `/api/newsletter`. |
| `WHATSAPP_WEBHOOK_URL` | Alternative: any JSON webhook (Make, Zapier, n8n) that forwards lead notifications to WhatsApp. |

When no WhatsApp transport is configured, lead endpoints still save the
request and return a `wa.me` link the visitor can tap so no lead is lost.

## API routes

- `GET /api/properties` - all listings (Vercel KV or bundled JSON)
- `GET /api/properties/[slug]` - single listing
- `GET /api/search?listing=&type=&location=&minPrice=&maxPrice=&beds=&q=` - filtered listings
- `POST /api/valuation` - save valuation / viewing / contact lead, notify WhatsApp
- `GET /api/blog` - market insight articles parsed from MDX
- `POST /api/newsletter` - save subscriber email to Vercel KV

## Images

All photography is free stock from Pexels, saved locally under
`public/images/` with base64 blur placeholders generated by
`scripts/process-images.mjs`. See `IMAGE-CREDITS.md` and `/image-credits`
for attribution. To reprocess: `npm run images:process`.
